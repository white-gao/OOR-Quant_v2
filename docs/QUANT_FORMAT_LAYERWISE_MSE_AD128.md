# AD128 逐层量化重建 MSE 对比

## 实验口径

- 模型：1.7B，BF16 算子执行。
- 数据：AD calibration split 前 128 条，`calib_offset=0`。
- 量化范围：Transformer block 内 7 个 Linear；权重 per-output-channel，激活动态 per-token。
- 局部 probe 中，每个量化 block 都接收对应层的全精度输入，因此不包含前序量化误差传播。
- 累计 probe 中，全精度流和量化流分别接收各自上一层输出，用于测量量化前缀传播后的累计偏离。
- 六组局部实验的全精度 target、总元素数和 target squared sum 完全一致，因此绝对 MSE 与相对 MSE 可以直接横向比较。

定义：

$$\mathrm{MSE}_l = \frac{\sum_i (Y^Q_{l,i}-Y^{FP}_{l,i})^2}{N_l}$$

$$\mathrm{Relative\ MSE}_l = \frac{\sum_i (Y^Q_{l,i}-Y^{FP}_{l,i})^2}{\sum_i (Y^{FP}_{l,i})^2}$$

## 局部误差观察

- W4A8 的 Global MSE 为 2.503419，仅比 W4A16 的 2.439577 高 2.62%；在 FP4 权重条件下，FP8 激活带来的附加误差已经很小。
- W4A8 相比 FP4 W4A4 将 Global MSE 降低 90.04%，说明把激活从 FP4 提升至 FP8 基本消除了 W4A4 的主要激活瓶颈。
- W4A8 的 MSE 仍是 FP8 W8A8 的 22.44 倍；激活提升至 FP8 后，剩余误差主要来自 FP4 权重。
- 在 W4A4 中，W16A4 的 Global MSE 是 W4A16 的 9.19 倍，说明其主要误差来自 FP4 激活量化。
- W4A16 与 W16A4 的 MSE 之和为 24.858086，完整 FP4 W4A4 为 25.134353；额外交互项仅为 0.276267，误差基本呈加性。
- Layer 2：W4A4/W16A4 的相对 MSE 约为 89%，而 W4A8 与 W4A16 都约为 0.49%；FP8 激活彻底消除了该层的 FP4 激活崩溃。
- Layer 27：W4A4 相对 MSE 为 37.4164%，W4A8 为 3.3236%，W4A16 为 3.2483%；W4A8 再次几乎贴近 W4A16。
- W4A8 与 W4A16 的逐层曲线基本重合，因此在当前动态 per-token 粒度下，FP8 激活已经足以承担该模型的激活表示；W4A8 后续优化应优先关注 FP4 权重。

## 累计误差：两流 Prefix-Quantized Probe

### 定义与口径

累计 probe 使用与局部 probe 相同的模型、AD calibration 前 128 条样本、BF16 算子执行、权重量化粒度和激活动态 per-token 粒度，但维护两条真实传播流：

$$H_l^{FP}=B_l^{FP}(H_{l-1}^{FP})$$

$$H_l^{Q}=B_l^{Q}(H_{l-1}^{Q})$$

两条流从相同的 Layer 0 输入开始。在第 $l$ 层记录：

$$\mathrm{Cumulative\ MSE}_l=
\frac{\sum_i(H_{l,i}^{Q}-H_{l,i}^{FP})^2}{N_l}$$

$$\mathrm{Cumulative\ Relative\ MSE}_l=
\frac{\sum_i(H_{l,i}^{Q}-H_{l,i}^{FP})^2}
{\sum_i(H_{l,i}^{FP})^2}$$

求和范围覆盖全部 128 条样本、token 和 hidden channel。该值表示量化完整前缀 0..l 后在第 $l$ 层端点的累计隐藏状态偏离，不等于第 $l$ 层单独注入的误差，也不能直接分解成该层对最终误差的贡献。

本次累计 probe 已完成两组主设置：FP8-W/FP8-A 和 FP4-W/FP8-A。

### 累计曲线观察

- **Layer 0--1 建立初始偏离，但尚不能据此证明都值得保护。** FP8 的累计 Relative MSE 为 0.2824% 和 0.2808%，基本持平；W4A8 则从 3.4262% 上升至 5.7067%，说明 W4A8 的前两个量化 block 组成的前缀值得重点关注。
- **Layer 2 的绝对 MSE 跳升不能直接解释为归一化误差放大。** FP8 的累计绝对 MSE 从 Layer 1 到 2 增加 17.30 倍，W4A8 增加 27.80 倍；但累计 Relative MSE 分别从 0.2808% 降至 0.0780%、从 5.7067% 降至 2.5462%。这说明 Layer 2 的全精度输出能量显著增大。局部 probe 仍显示 Layer 2 相对 Layer 3 异常，但累计 A8 结果没有证明它进一步放大了归一化前缀误差。
- **Layer 3--14 是缓慢累积区间。** FP8 累计 Relative MSE 从 0.0784% 增至 0.1478%，W4A8 从 2.5530% 增至 3.3651%。
- **Layer 15--26 进入持续加速区间。** FP8 增至 0.8500%，W4A8 增至 11.2741%，说明后半段整体的累计效应不能被少数离散敏感层完全概括。
- **Layer 27 是最明确的累计误差跳变点。** FP8 Relative MSE 从 Layer 26 的 0.8500% 增至 2.0220%，放大 2.38 倍；W4A8 从 11.2741% 增至 30.5541%，放大 2.71 倍。

### 对“敏感层保护”结论的限制

当前结果支持“局部重建误差不足以描述真实量化模型，必须考虑量化前缀误差积累”，但累计曲线本身仍不是因果层重要性排序：

- Layer 0、1 是早期敏感候选；W4A8 下 Layer 1 的累计增长更明显。
- Layer 2 是稳定的局部异常层，尤其对 A4 激活敏感，但 A8 累计 Relative MSE 没有向上跳变。
- Layer 27 是当前最明确值得优先保护或重点优化的 block。
- Layer 15--27 呈现区域性的持续累积，仅保护少数离散 block 未必足够。

若要证明某层“值得保护”，需要在其余层保持量化的真实混合精度路径中，每次仅恢复一个 block 为高精度，再比较最终 Layer 27 累计 Relative MSE 或最终 logits 偏离。
