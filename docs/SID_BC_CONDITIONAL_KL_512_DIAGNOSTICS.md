## 结论

SID_b 条件 KL 的 mean ΔKL 为 `-0.004993`，但 95% CI `[-0.022705, 0.012689]` 跨 0，不能确认存在稳定变化。
SID_c 条件 mean KL 从 `2.296417` 增至 `2.361314`（约 `+2.83%`），mean ΔKL 为 `+0.064897`，配对 95% CI `[0.019573, 0.110024]` 全部大于 0，说明 LFQ 对该后续位置产生了可泛化的负迁移。

SID_c 的 FP top-32 overlap 同时下降 `1.13 pp`，正确 SID_c 类型的全词表概率质量下降 `0.354 pp`，ground-truth scoped hit@1/hit@32 分别下降 `0.98/0.59 pp`；这些方向与完整 benchmark 在较大 beam k 上的掉点一致。结论支持“只在 SID_a 位置优化共享的最后一层参数会部分牺牲 SID_c”，但该实验只能说明它是合理成因，不能证明它是全部掉点的唯一来源。

本报告是 [SID_a 512-sample diagnostics](SID_A_LFQ_512_DIAGNOSTICS.md) 的后续定位实验。

## 实验控制

- 数据：与 SID_a 诊断相同的 AD `test` 前 `512` 条，offset `0`；sample id `0`–`511`。
- 每条样本取第一个 ground-truth SID，与现有 `sid_ppl_max_items=1` 口径一致。
- SID_b 输入：`prompt + a_gt`；SID_c 输入：`prompt + a_gt + b_gt`。三个模型使用完全相同的 oracle prefix。
- SID_b/SID_c 各自在 `8192` 个对应 token 上重新归一化；同时单独测量正确 token 类型占全词表的概率质量。
- FP：原始 BF16；MSE-LWC 与 strict-prefix LFQ-LWC 均为 W4A16 asymmetric LWC、无 LET。LFQ 实验只有第 27 层优化目标不同。
- batch size `4`，随机种子 `42`。

## 解释边界

- Ground-truth teacher forcing 隔离了条件分布质量，但不会复现量化模型用自身 SID_a 候选继续生成时的 exposure effect。
- 子词表 KL 衡量正确类型内部的相对分布；全词表 scope mass 与 full-vocab rank 用来补充类型外概率泄漏。
- 512 样本足以观察较大的系统性偏移；接近零的小幅 hit@k 波动仍可能是抽样噪声。

本报告只保留聚合统计；一次性诊断脚本和中间 logits 已在运行后删除。
